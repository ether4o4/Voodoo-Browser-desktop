Compatibility & lifecycle

Scripts run in separate isolated Chromium worlds. Declared grants, matching rules and network permissions are enforced. Script values are stored natively, separately from website storage. Internal Voodoo pages are excluded. This supports a documented subset of userscript APIs.

Disabling a script stops future automatic injections. Reload the target page to remove its existing timers and DOM changes. Manual activation explicitly reloads the website once before running. Saving alone does not reload or run it. Background tabs are throttled to reduce resource use.
