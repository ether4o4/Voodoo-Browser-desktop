Extract the Windows ZIP and run **Voodoo.exe**. Keep its files together. This unsigned development preview opens on demand, has no startup task or background service, and supports an explicit encrypted link over the same Wi-Fi or phone hotspot. There is no hosted relay or recurring hosting bill.

The mobile preview removes the dedicated Suno section and adds Device link. It installs separately as `com.ether4o4.voodoo.dev`, preserving the original app; it does not import that app's profile.

These URLs stay the same as verified preview assets are updated. Physical phone pairing and an independent security audit remain outstanding. Keep high-value credentials in an established browser/password manager.
